# Measurement notes

The Darwin interfaces below were checked against Apple's published XNU headers and implementation. These references describe the API contract; the macOS workflow must still compile against an actual SDK and run the smoke tests. No Darwin/AppKit build can be claimed from Linux core tests.

- [`libproc.h`](https://github.com/apple-oss-distributions/xnu/blob/main/libsyscall/wrappers/libproc/libproc.h): `int proc_pid_rusage(int pid, int flavor, rusage_info_t *buffer)`, returns zero on success and -1 on error. The small C adapter keeps its buffer cast out of Swift's imported pointer types.
- [`sys/resource.h`](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/resource.h): `rusage_info_t` is `void *`; `RUSAGE_INFO_V0` selects `struct rusage_info_v0`. This includes `ri_phys_footprint`, `ri_proc_start_abstime`, and `ri_proc_exit_abstime`, all `uint64_t`. The adapter rejects failed reads and exited processes, and uses the start time with PID and canonical bundle path as identity. Footprint is for one process; no unverified helper attribution is attempted.
- [`mach/vm_statistics.h`](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/mach/vm_statistics.h): speculative pages are already counted in `free_count`. `compressor_page_count` is the pages occupied by compressed data. `swapouts` counts lifetime pages swapped out via compressor segments. Multiplying counter deltas by host page size is an estimate based on that VM counter, not physical disk I/O measurement.
- [`kern_memorystatus_notify.c`](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/kern/kern_memorystatus_notify.c): the `kern.memorystatus_vm_pressure_level` sysctl converts internal pressure levels to dispatch flags. [`event_private.h`](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/event_private.h) defines normal/warning/critical as 1/2/4. Other values, missing sysctl support, and wrong-sized reads are unknown, never silently critical or healthy. This is an implementation-specific sysctl, not a promise of future macOS compatibility.
- [`mach/mach_time.h`](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/mach/mach_time.h): `mach_continuous_time(void)` returns `uint64_t` and advances during sleep. The adapter converts ticks using `mach_timebase_info`. Nonfinite times, backwards/duplicate timestamps, or gaps over 45 seconds do not carry a rate forward.

## Limits and manual checks

- Pressure is sampled, not a continuous trace. Recent pressure counts are observations, not a percent-of-time estimate.
- History is bounded by both time and count. Rapid manual refreshes can shorten the available interval. Counter failure breaks only swap continuity; independently successful pressure readings remain usable.
- Per-app changes are main-process comparisons between adjacent successful collection rounds, not a five-minute app growth metric and not a leak detector.
- Quit uses `NSRunningApplication.terminate()` only after an identity/eligibility recheck. It never kills by display name or uses force termination. No API can promise an app has saved its work; the user must decide whether to proceed.
- Before release on a Mac: inspect the small dot and accessibility label, open each submenu, check same-named apps, exercise Cancel and a normal app quit, leave a confirmation dialog open while restarting the target, and sleep/wake for more than 45 seconds. Verify histories resume with a fresh baseline. Check unavailable readings using a denied/vanished process rather than treating missing values as zero.
